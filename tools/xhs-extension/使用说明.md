# 行迹 · 小红书线索采集扩展（v1.3.0）

路径：`/Users/weishengqiu/IdeaProjects/whereabouts/tools/xhs-extension/`

## 一、v1.3 修了什么

1. **「装了扩展仍提示不生效」**：旧版 `bridge.js` 在内容脚本的 isolated world 里写 `window.__XHS_COLLECTOR__`，网页里的 React 代码读不到这个属性（Chrome 的隔离世界设计）。v1.3 改成 `window.postMessage` 双向握手，页面发 `PING`，扩展回 `STATUS`，可靠检测安装状态与登录态。
2. **不用再手动采集/复制/粘贴**：点平台上的「生成定制方案」，会自动完成「拆检索词 → 后台串行采集 → 自动导入 → 注入模型」。用户只需**安装扩展 + 登录小红书各一次**。
3. 后台采集用**非活动标签页**，打开小红书搜索页、只读当前已渲染 DOM、采完立刻关闭；带 busy 锁防止并发。

## 二、安装 / 更新（Chrome、Edge）

1. 地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启**开发者模式**。
2. 点「加载已解压的扩展程序」，选择上面的目录。
3. **如果之前加载过旧版本**：必须点这张扩展卡片上的「重新加载」，确认版本号显示 `1.3.0`。只改代码不重新加载，浏览器仍在跑旧版。
4. 在自己的浏览器里登录小红书一次。

> 重要：WorkBuddy 右侧的内置预览窗口**不能加载浏览器扩展**。请用系统 Chrome/Edge 打开 `http://150.158.179.138:8888`，才会触发扩展。

## 三、日常使用（自动模式）

1. 打开平台，填写旅行需求。
2. 保持「自动生成小红书线索」勾选（默认勾选）。
3. 点「生成定制方案」。实采卡片会显示进度：`检测扩展 → 检查登录 → 拆词 → 逐条采集`；每条关键词采完自动导入。
4. 方案与后续指南会自动带上这些线索（明确标注为「用户实采、非评分」）。

如果扩展没装 / 小红书没登录：只会在实采卡片给出提示，**不会阻断方案生成**。补齐一次后，以后点生成就是全自动。

## 四、手动兜底（可选）

1. 在小红书打开搜索结果页或笔记详情页，确认已登录。
2. 点工具栏扩展图标 →「采集当前页」→「复制 JSON」或「下载 JSON」。
3. 回到平台实采卡片，展开「手动导入 JSON」，选分类、粘贴 JSON、点导入。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 平台仍显示「扩展未安装」 | 用的是 WorkBuddy 内置预览窗口 / 改了代码没重新加载 / 扩展被禁用 | 用系统 Chrome/Edge 打开本站；在 `chrome://extensions` 点「重新加载」并确认 `1.3.0`；确认扩展开关打开 |
| 提示小红书未登录 | 登录态过期或从未登录 | 在小红书网页登录一次，再点生成方案 |
| 自动采集 0 条 | 小红书改版导致选择器失效 / 搜索页没渲染出卡片 | 更新 `parser.js` 选择器；或打开搜索页用手动采集确认 |
| 浏览器标签页闪了一下 | 后台自动打开/关闭小红书搜索页 | 正常现象，采集完自动关闭 |
| 「浏览器不允许在扩展/设置页注入」 | 在 `chrome://` 页面点了采集 | 打开真实小红书页面再点 |

## 七、边界

扩展只读用户浏览器当前已渲染的 DOM，不主动发网络请求、不读 Cookie、不模拟登录、不绕过风控、不批量轮询。线索只保留标题/作者/摘要/点赞数/官方链接，**没有评分**；点赞只是热度，平台会标注需回源核实。是否使用采集内容由用户自行判断。
